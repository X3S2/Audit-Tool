# Release-Checkliste

Vor jedem GitPush müssen die folgenden Punkte geprüft werden:

- [ ] README aktualisiert
- [ ] Changelog aktualisiert
- [ ] Versionierung angepasst
- [ ] Backend buildet fehlerfrei
- [ ] Frontend buildet fehlerfrei
- [ ] Docker Compose startet ohne kritische Fehler
- [ ] Rollen und Adminzugriffe überprüft
- [ ] Login/Session-Timeout 8 Stunden validiert
- [ ] Bild-Uploads und Komprimierung geprüft
- [ ] Exports und ZIP-Workflow getestet
- [ ] Backup/Restore analysiert
- [ ] Sicherheitsansicht und Secrets geprüft
